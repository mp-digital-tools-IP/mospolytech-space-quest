# Финальный хаб космических миссий

Главный экран теперь является единым входом в четыре основные игровые механики:

1. Орбитальная стыковка — `missions/docking/`
2. Мягкая посадка — `missions/landing/`
3. Вывод на орбиту — `missions/orbit/`
4. Очистка орбиты — `missions/debris/`

Режим `Пройти все 4` реализован через `campaign.html`: существующие игры запускаются внутри same-origin iframe, а родительский экран отслеживает только успешный финальный экран каждой миссии. Это позволяет сохранить автономность всех четырёх игр и не вносить в них отдельную campaign-логику.

Результаты полного маршрута хранятся только в `sessionStorage` текущей вкладки. После четвёртой миссии пользователь возвращается на корневой экран с `?complete=1`, где показывается общий финал.

Мобильная компоновка корневого хаба не использует document scroll; на iPhone карточки расположены сеткой 2×2.
