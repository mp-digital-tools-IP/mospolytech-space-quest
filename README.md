# Московский Политех — Космический квест

Одностраничная интерактивная игра для стенда Московского Политеха на «Ярмарке космических профессий — 2026».

## Квест 01
«Собери спутник для миссии»: участник за 60 секунд выбирает три необходимых модуля спутника наблюдения Земли и устанавливает их в соответствующие зоны.

Проект сделан как статическая HTML-страница без внешних библиотек, чтобы корректно работать на iPad и в мобильном Safari.
